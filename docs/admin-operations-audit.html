وجود زر أو جدول في الصفحة لا يعني أن العملية مفعّلة. بيانات الاشتراكات والمدفوعات وتذاكر الدعم تجريبية، وأرقام الفروع مولّدة من ترتيب العيادات. لا تصلح هذه الأجزاء حاليًا كتقارير أعمال فعلية.

حصر الصفحات والعمليات

الصفحةالعمليات الموجودةالحالة الفعلية
تسجيل الدخول والخروج
/admin/login		التحقق من البريد وكلمة المرور، إنشاء جلسة، استعادة بيانات الأدمن، الخروج، رفض الجلسة غير الصالحة والحساب غير النشط.مفعّل ومختبَر. خيار Remember me ظاهر لكن قيمته لا تُرسل للسيرفر؛ مدة الرمز محددة حاليًا بـ30 يومًا.
Dashboard
/admin/dashboard		إجمالي العيادات والنشطة والموقوفة والجديدة هذا الشهر، توزيع الحالات، آخر العيادات المسجلة، إعادة المحاولة عند فشل التحميل.جزئي. أعداد العيادات حقيقية. جدول «Recently Renewed Subscriptions» يستعمل آخر العيادات وتواريخ تعديلها وخططًا تجريبية، ولا يعرض تجديدات اشتراكات فعلية.
Clinics
/admin/clinics		عرض وبحث بالاسم وصاحب العيادة والبريد والهاتف، تصفية الحالة، صفحات نتائج، فتح التفاصيل والتعديل والمستخدمين، إيقاف وتفعيل وحذف بعد التأكيد.العمليات الأساسية مفعّلة ومختبَرة. حالة الاشتراك المعروضة مشتقة من حالة العيادة وليست سجل اشتراك. حالتا Trial وInactive في الفلتر ليستا ضمن حالات إنشاء العيادة الحالية.
Add Clinic
/admin/clinics/create		إضافة بيانات العيادة والاتصال والموقع والحالة والملاحظات، إنشاء أول مستخدم اختياريًا، تحقق المدخلات، حفظ وإلغاء.مفعّل ومختبَر. إنشاء العيادة وأول مستخدم طلبان منفصلان؛ إذا فشل المستخدم تبقى العيادة مع رسالة توضح ذلك.
تفاصيل وتعديل العيادة
/admin/clinics/$id
/admin/clinics/$id/edit		عرض وتعديل البيانات، الرجوع للقائمة، التفعيل والإيقاف والحذف، إدارة مستخدمي العيادة.العمليات الأساسية مفعّلة. بيانات Subscription Plan = Professional وBilling = Yearly ثابتة في واجهة التفاصيل.
مستخدمو العيادة
/admin/clinics/$id/users		عرض وبحث وصفحات نتائج، إضافة مستخدم، تعديل الاسم والبريد والهاتف والدور والحالة، تغيير كلمة المرور مع تأكيدها، تفعيل وتعطيل وحذف بعد التأكيد، إعادة محاولة التحميل.مفعّل ومختبَر. الأدوار المتاحة: مالك عيادة، مدير عيادة، موظف. تظهر الوظائف نفسها داخل صفحة تفاصيل العيادة وتعديلها.
Subscriptions
/admin/subscriptions		Create، Renew، Upgrade، Downgrade، Cancel؛ جدول الخطط والبداية والنهاية ودورة الدفع والحالة.غير موصول. الجدول بيانات تجريبية والأزرار بلا تنفيذ أو API.
Financial
/admin/financial		إيرادات ومدفوعات معلقة، عرض فاتورة، تعليمها كمدفوعة، تنزيل الفاتورة.غير موصول. الأرقام والفواتير تجريبية والأزرار بلا تنفيذ أو API.
Clinic Accounts
/admin/users		عرض حسابات العيادات وفتح View وEdit، زرا Suspend وActivate.جزئي. قائمة العيادات وفتح التفاصيل والتعديل يعملان. خطة الاشتراك مولّدة تجريبيًا؛ زرا الإيقاف والتفعيل هنا غير موصولين رغم توفر الوظيفة في صفحة Clinics. يعرض القسم أول 50 عيادة فقط.
Support Center
/admin/support-center		عرض التذاكر، Reply to Clinic، Close Ticket، وصف إشعارات البريد.غير موصول. تذاكر تجريبية؛ لا يوجد تنفيذ للرد أو الإغلاق أو إشعارات البريد من هذه الشاشة.
Branch Statistics
/admin/branch-statistics		إجمالي الفروع والنشطة والفروع لكل عيادة.أرقام تجريبية. أسماء العيادات من API، أما أعداد الفروع فتُولّد حسب ترتيبها، وليست من قاعدة بيانات فروع.
Backups
/admin/backups		Create Backup، Restore Backup، Download Backup.غير مفعّل. الأزرار معطّلة وتعرض Coming Soon؛ لا توجد مسارات تنفيذ.
Settings
/admin/settings		اسم وشعار النظام، طرق الدفع، الخطط، معلومات الشركة، Save Settings.غير موصول. حقول بقيم ابتدائية وزر حفظ بلا تنفيذ؛ اختيار ملف الشعار لا يرفعه.

ما تم إصلاحه في هذه المراجعة

  • تثبيت هيكل الأدمن والقائمة والهيدر في الجذر، مع فحص الجلسة مرة واحدة بدل تكراره في كل صفحة.
  • استبدال روابط الأدمن الداخلية التي تعيد تحميل الموقع بروابط التنقل داخل التطبيق.
  • تطبيق تنسيق الأدمن قبل الرسم، ومنع حلقة التحويل بسبب وجود رمز جلسة مرفوض.
  • ربط حماية الصفحة بالصفحة المعروضة فعليًا أثناء الانتقال، حتى لا يظهر محتوى محمي عند التحويل لشاشة الدخول.
  • إضافة اسم صاحب العيادة إلى البحث الفعلي، وضبط الحد الأدنى لحجم صفحات النتائج في قوائم الأدمن.

تغطية الاختبارات وحدودها

  • اختبار تلقائي للتنقل عبر صفحات الأدمن مع التحقق أن عناصر القائمة والهيدر نفسها لا تُحذف أو تُنشأ من جديد، وأن فحص الجلسة يُطلب مرة واحدة.
  • اختبارات واجهة لإنشاء وتعديل العيادات والمستخدمين، البحث والتصفية، تفعيل وتعطيل الحسابات، تأكيد وإلغاء الحذف، وفشل الحفظ وإعادة المحاولة.
  • اختبارات API للإحصاءات والتصفح والترقيم، الحقول غير الصحيحة والتكرار، تغيير كلمات المرور، حظر الحسابات الموقوفة، عزل جلسات الأدمن عن جلسات العيادة، والدخول والخروج.
  • اختبار تنقل فعلي في المتصفح المحلي بين أقسام القائمة العشرة باستخدام باك إند وقاعدة بيانات اختبار منفصلة.
  • الموقع المنشور أعاد التوجيه إلى صفحة الدخول؛ لم تُنفّذ تغييرات على حسابات أو بيانات إنتاجية. الميزات التجريبية أعلاه لا تُحتسب كعمليات ناجحة لمجرد ظهور صفحتها.
  • للتشغيل المتكرر: ملفات AdminNavigation.test.tsx وClinicForm.test.tsx وClinicUsersPanel.test.tsx في الواجهة؛ AdminOperationsTest.php وDashboardWorkflowTest.php في الباك إند.

مصادر الحصر: routes/api.php وAdminLayout.tsx وSuperAdminSections.tsx وصفحات admin.* ونماذج ClinicForm وClinicUsersPanel. المسار /admin نفسه تحويل إلى Dashboard ولا يُعد صفحة إضافية.
